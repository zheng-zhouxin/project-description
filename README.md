# 供应链知识平台

**项目时间**：2024.12 - 2025.03

**项目角色**：前端负责人

**项目背景**：为提升供应链文档管理能力与跨部门协作效率，搭建基于微前端架构的知识平台，承载流程中心、资料管理、系统配置等业务模块。

**项目描述**：供应链领域微前端应用，基于 MicroApp 实现多应用集成，覆盖首页、流程中心、系统知识、项目资料、系统配置模块，支撑内部文档管理与跨团队协同。

**项目职责**：负责团队管理、技术选型、核心业务开发，统筹项目从需求评估到上线交付全流程。

**技术栈**：React18、Umi4、Ant Design、TypeScript、MobX、i18next、DevOps、MicroApp、朱雀框架、Dicc 组件库

**核心贡献**

1. 统筹团队需求管理，对接产品评审 PRD，输出开发文档，完成需求与人天评估；落地 ESLint+Prettier+Husky，统一团队编码规范。

2. 基于内部朱雀框架与 Dicc 组件库，从零搭建项目，完成 MicroApp 微前端架构设计与落地。

3. 依托 i18next 实现平台国际化，静态文案采用插件翻译，动态数据支持后台配置翻译，达成全平台 100% 国际化覆盖。

4. 开展多维度性能与体验优化，使用骨架屏解决首屏白屏，进度条优化大文件上传交互，通过 Emotion+Tooltip 处理文本溢出展示问题。

5. 依托 DevOps 搭建流水线，完成项目自动化构建、部署，打通发布与基础监控能力，保障项目平稳上线。

# 供应链一站式平台

**项目时间**：2024.08 - 2024.12

**项目角色**：前端负责人

**项目背景**：为提升企业供应链整体数字化管理效率，搭建微前端架构供应链工作台基座平台，整合多业务模块，实现供应链业务统一管控与高效协同。

**项目描述**：基于 MicroApp 架构搭建的供应链工作台微前端基座应用，涵盖首页、星河待办、GenAI 智能助手、应用列表、数字化需求、报表中心、系统配置等核心模块，支撑全链路供应链数字化管理业务。

**项目职责**：全权主导项目微前端架构设计与落地开发，负责工作台基座搭建、数字化需求、报表中心等核心子应用开发与迭代，统筹前端整体业务落地。

**技术栈**：React 18、Umi 4、Ant Design、TypeScript、MicroApp、ECharts、WebGis、React-Grid-Layout、MobX、Ahooks

**核心贡献**

1. 主导 MicroApp 微前端架构设计与落地，完成供应链工作台基座搭建，独立实现数字化需求、报表中心等核心子应用开发，保障多子应用稳定集成运行。

2. 基于 MobX 设计全局状态通信方案，优化星河待办多子应用数据互通逻辑，解决数字化需求多入口、多状态审批同步问题，提升业务审批流畅度。

3. 统一前端埋点规范体系，接入天眼 SDK，完成 100+ 页面与接口埋点采集；针对性优化应用列表模块埋点逻辑，实现业务数据统计与 Top5 数据排行榜可视化展示。

4. 实现子应用 keep-alive 页面缓存能力，结合 useDebounce 防抖机制优化 ECharts 大数据可视化看板渲染逻辑，有效降低高频渲染压力，提升报表页面流畅度与稳定性。

# 吉祥号码管理系统（PC端）

**项目时间**：2024.04 - 2024.06

**项目角色**：前端开发工程师

**项目背景**：旧系统菜单分散、组件能力薄弱、批量操作缺失，难以满足号码业务日益增长的处理需求，需重构一套集中化管理的吉祥号码管理平台。

**项目描述**：面向号码业务管理的中后台系统，覆盖工作台、待办、申请单管理、号码管理、权限管理、系统管理等菜单模块，支撑号码业务的申请、预留、选号全流程办理。

**项目职责**：参与需求评审，主导项目选型与搭建，负责核心模块开发、公共组件抽离及项目代码优化。

**技术栈**：React、Umi、Ant Design Pro、TypeScript、React Router、Hooks、Axios

**核心贡献**

1. 基于 Umi 脚手架搭建项目，配置 Mock 模拟接口数据、Proxy 解决跨域、ESLint 规范代码风格，提升团队开发效率。

2. 封装 Axios 拦截器统一处理接口请求与报错，开发登录模块并配置 Router 路由权限控制菜单展示，打通系统公共能力。

3. 基于 Ant Design Pro 封装 Tab、表单、表格等模块化组件，将旧系统 30+ 个二级菜单进行动态配置，实现菜单集中化管理。

4. 相比旧系统拓展页面组件能力，新增批量新增、批量删除、批量预留等批量化操作功能，提升系统业务办理能力。

5. 新增号码选号功能，封装选号控件并与后台大数据对比推选优质号码，提高号码的预留率和申请率。

6. 抽离查询、上传、导出等公共组件实现逻辑复用，使用 Hooks 缓存钩子函数减少组件重复渲染，提升页面性能。

# 大音小屏系统（H5端）

**项目时间**：2023.01 - 2023.06

**项目角色**：前端开发工程师

**项目背景**：大音平台原有 PC 端能力难以满足一线人员移动办公场景，需将 PC 端能力向 H5 端延伸，支撑现场工单处理与信息查看。

**项目描述**：大音平台的 H5 端转型项目，覆盖信息中心、省内工单、集团单、服务规范检查等模块，支撑一线人员的移动化办公与工单处理业务。

**项目职责**：参与需求澄清，还原 UI 设计图，开发信息中心模块、省内工单模块，并负责项目性能优化。

**技术栈**：React、Ant Design Mobile、TypeScript、Ahooks、Axios、Mock、Sass

**核心贡献**

1. 基于 Ant Design Mobile 组件库，封装信息中心待办、申请、历史记录页面的筛选栏、列表和详情组件，高度还原 UI 设计图。

2. 通过 useRequest 处理列表数据请求，结合 useVirtualList 优化列表数据显示，解决列表滚动卡顿问题，提升用户体验。

3. 封装省内工单模块业务组件，使用 useForm 处理表单数据的获取、验证、提交操作，实现工单的创建、处理、提交等功能。

4. 使用 useDebounce 优化工单信息搜索功能，useThrottle 优化工单滚动事件，避免频繁操作，提高页面操作性能。

5. 通过懒加载、骨架屏优化图片渲染效果，使用雪碧图、IconFont、Base64 代替图片文件，减少网络请求，提高页面加载速度。

# 计费账务生产平台（PC端）

**项目时间**：2022.07 - 2022.12

**项目角色**：中级前端开发工程师

**项目背景**：中国移动计费账务生产平台登录加密能力薄弱、业务监控能力缺失，需在前后端不分离架构下补齐安全与监控能力。

**项目描述**：前后端不分离的计费账务管理系统，主要用于管理中国移动计费账务，覆盖首页、待办列表、账务审批、业务监控、系统管理等功能模块。

**项目职责**：参与需求评审，提供解决方案，优化平台登录加密，开发业务监控模块。

**技术栈**：React、Ant Design、Hooks、Egg.js、Node.js、MySQL、Progress、Koa、MongoDB

**核心贡献**

1. 使用 RSA 加密技术提升登录密码密钥长度，前台通过 jsencrypt 插件公钥加密，后台通过 node-rsa 插件私钥解密，增强平台安全性。

2. 通过 Linux 命令创建远程目录，使用 egg-cron 插件实现每隔 12 小时扫描目录，并将文件信息进行入库处理操作。

3. 使用 egg-mysql 插件连接数据库，编写 SQL 脚本创建表模型，通过 Controller 控制器实现添加、修改、删除、查询接口开发。

4. 封装自定义 Hooks 实现页面表格增删查改功能，完成异动数据处理表、异动数据结果表、异动数据日志表的监控业务。

**项目描述**：为提高公司投放部和市场部工作效率而开发的批量广告投放工具，支持对接腾讯、头条等主流广告投放平台，覆盖广告计划、广告组、广告创意、批量配置等模块。

**项目职责**：负责核心模块开发，包括广告计划、广告组、广告创意、批量配置等模块。

**技术栈**：React、Redux、JavaScript、Ant Design、Axios、React-Router-Cache-Route

**核心贡献**

1. 对接腾讯、头条等广告投放平台开放的 Marketing API 文档，整理系统与平台的授权信息并制定开发文档。

2. 根据 UI 设计稿，使用 Ant Design 组件完成广告计划、广告组、广告创意、批量配置等模块的页面布局开发。

3. 通过 Axios 完成后端接口数据交互，Redux 进行数据状态管理，Router 进行路由跳转，react-router-cache-route 实现页面缓存。

4. 运用 React.PureComponent、React.memo、React.lazy 和 React Hook 函数等进行性能优化。

5. 使用 Webpack 打包优化，GitLab 管理代码版本，利用 OSS 上传服务器并发布部署。

# H5游戏活动落地页

**项目时间**：2020.08 - 2020.12

**项目角色**：前端开发工程师

**项目背景**：游戏运营需通过落地页向玩家推送福利活动与文章资讯，原有公告方式触达效率低，需搭建平台级游戏公告能力，实现运营内容快速配置与发布。

**项目描述**：平台级游戏公告落地页，通过后台配置游戏运营公告，让玩家了解游戏内的各种福利活动和文章资讯，涵盖活动展示、资讯文章、轮播推广等内容模块。

**项目职责**：负责落地页前端开发，包括页面布局、组件封装、状态管理与接口对接。

**技术栈**：Vue3、Vant、Swiper、Vuex、Vue-Router、Axios、Sass、JavaScript

**核心贡献**

1. 基于 Vue3 脚手架搭建项目，结合 rem 与 Vant 框架进行移动端 UI 布局，实现多终端自适应适配。

2. 封装活动卡片、资讯文章、公告栏等业务组件，结合后台配置数据动态渲染公告内容，提升运营内容配置效率。

3. 使用 Swiper 实现首页活动轮播推广展示，结合 Vuex 进行全局状态存储管理，实现公告数据跨组件共享。

4. 通过 Vue-Router 管理项目页面跳转与路由配置，配置 Axios 拦截器统一处理网络请求与接口报错。

5. 采用图片懒加载、骨架屏等手段优化落地页加载性能，减少首屏白屏，提升玩家浏览体验。
